# Local UI fonts

The dashboard uses the same fonts as ReplyMaven. They are served locally so
Cloudflare's `font-src 'self'` policy can stay in place.

- Inter variable, weights 400–700: Google Fonts, https://fonts.google.com/specimen/Inter.
  The SIL Open Font License is included in `Inter-OFL.txt`.
- Switzer, weights 500, 600, 700: Indian Type Foundry / Fontshare,
  https://www.fontshare.com/fonts/switzer. License: https://www.fontshare.com/licenses.

Downloaded from the official Google Fonts and Fontshare CSS endpoints on
2026-10-11. Files are unmodified WOFF2 assets.
